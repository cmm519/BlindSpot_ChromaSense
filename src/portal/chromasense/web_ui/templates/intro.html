Introduction

CVD profiles

Color vision deficiency (CVD) changes which colors look alike. A CVD profile tells ChromaSense which colors to check for you. It has two parts:

  • Type: protan, deutan, tritan, or achromatopsia. Choose no CVD if color is not what you need help with. You still get the color list, shapes, text, color identification, and AI interpretation.
  • Severity: a value from 0 to 1, where 1 is complete.

Your profile stays in this browser. You can change it on the Settings page. ChromaSense does not diagnose CVD. To learn about your own color vision, ask an eye care professional.

Enhancement

A global color filter changes a whole image. ChromaSense first finds the pairs of colors that your profile makes hard to tell apart. It then changes only those colors, by moving them apart in lightness, and it leaves the rest of the image alone.

You can compare the original and enhanced images, change the strength, add a pattern to each confusable color group, and download the enhanced image.
